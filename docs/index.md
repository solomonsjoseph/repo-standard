# Documentation for repo-standard

Pages are grouped by what you want to do:

- Get started: tutorials in `tutorials/` walk you through a first success.
- How to: task guides in `how-to/` solve one specific problem each.
- Concepts: pages in `explanation/` describe the design and the reasons behind it.
- Reference: pages in `reference/` list the facts, options, and API details.

Contributor documentation, including decision records, lives in [dev](dev/index.md).

Until a tutorial exists, the quick start in the [README](../README.md) is the place to begin.
