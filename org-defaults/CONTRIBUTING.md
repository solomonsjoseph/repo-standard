# Contributing

Thank you for helping. This default applies to every repository of this
account that has no `CONTRIBUTING.md` of its own.

1. Open an issue first for any feature or bug, so the change is agreed on.
2. Keep each pull request small and focused on one change.
3. Describe what changed, why, and how you tested it.
4. Follow the style and tooling already used in the repository.

Repositories that follow the account's full repository standard have their
own `CONTRIBUTING.md` with the exact branch, commit, and check rules.
