# Default community health files

GitHub uses the files in this repository for every repository of this account
that does not have its own copy: CONTRIBUTING.md, SECURITY.md,
CODE_OF_CONDUCT.md, SUPPORT.md and the issue forms in `.github/ISSUE_TEMPLATE`.

Do not edit these files here. They are generated from
[repo-standard](https://github.com/__OWNER__/repo-standard)
by `scripts/sync.sh`, which opens a pull request with each update.
