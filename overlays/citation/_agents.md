
## Citation

This repository is research software that people cite.
[docs/how-to/cite.md](docs/how-to/cite.md) explains how.

- Keep `CITATION.cff` valid Citation File Format 1.2.0. When someone becomes
  an author, add them to `authors` with their ORCID when they have one, and
  ask the maintainer before removing anyone.
- Do not add `version` or `date-released`: GitHub and Zenodo take them from
  each release.
- When the maintainer has a concept DOI from Zenodo, it goes in `doi` and
  in the README badge; never invent one.
