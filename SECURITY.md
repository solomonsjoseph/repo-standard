# Security policy

## Reporting a vulnerability

Do not open a public issue. On a public repository, report it privately
through **Security > Report a vulnerability**. If the repository does not
show that option (private repositories), contact the maintainer privately
through the details on the owner's GitHub profile. You get an answer within
7 days.

Include what you found, how to reproduce it, and the affected version or
commit.

## Supported versions

Only the latest release receives security fixes.
